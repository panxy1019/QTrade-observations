# QTrade public research observations

Read-only latest market observations and persisted experiment summaries.
Public-source historical data, non-PIT, not trading or promotion authority.
Bounded current-chart Parquet is public; full research archives stay on the cluster.
Published every five minutes; consumers must check source clocks and publication age.
Historical simulation ledgers are explicitly labeled and carry no execution authority.
No credentials, live account state or arbitrary executable code are published.
